# Change Log

All notable changes to the "eddie sun" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.0]

- Each commit hash gets its own highlight color, with matching swatches in the sidebar.
- The sidebar shows how many lines of each commit are left, or "no code left" / "not found".
- The hash list is saved as you type and applied automatically while highlighting is on.
- Files touched by the listed commits are marked in the file tree without opening them.
- Short hashes work, git blame only reruns on save, and git is run without a shell.
